Gateway FinOps Run

Three applications call one LiteLLM gateway, which sends them to two model endpoints: Groq in the cloud and Ollama on this Mac. This page replays one run of demo.py from the gateway's spend ledger. Costs are in micro-dollars (µ$1 = $0.000001).

Architecture

Each application holds its own virtual key. Every request goes through the same five gateway stages, and each stage can reject it with its own status code before anything reaches a model.
