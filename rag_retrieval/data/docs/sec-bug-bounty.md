Security researchers can report vulnerabilities in Halcyon Cloud through our public bug bounty programme. Rewards range from $250 for low severity to $15,000 for critical issues.

We acknowledge reports within 2 business days. Do not access customer data, run denial-of-service tests or use social engineering.
