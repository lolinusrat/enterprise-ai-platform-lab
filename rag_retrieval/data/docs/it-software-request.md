Request software through the ServiceDesk catalog item SW-REQ. Approved tools from the software catalogue are installed automatically after your manager approves.

Tools that are not in the catalogue go through a security and privacy review, which takes about ten working days. Licenses costing more than $500 per year also need Finance approval.
