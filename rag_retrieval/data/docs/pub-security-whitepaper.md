Halcyon holds a SOC 2 Type II report and ISO 27001 certification; customers can request the SOC 2 report under NDA. Customer data is encrypted at rest with AES-256 and in transit with TLS 1.2 or higher.

An independent firm performs a penetration test every year, and we run a public bug bounty programme. Production access requires SSO, MFA and just-in-time approval.
