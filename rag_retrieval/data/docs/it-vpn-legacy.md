The Cisco AnyConnect VPN was retired on 31 March 2026 and replaced by GlobalConnect. This page is kept for historical reference only. Do not install AnyConnect on new laptops.

AnyConnect used the gateway remote.halcyon.example with a separate RSA token. Users connected manually from the system tray each time they worked from home, and all traffic was tunnelled, including video calls, which caused poor call quality.

Common AnyConnect problems were the "Login denied" message after a token resync and the client hanging at "Connecting". Neither applies to GlobalConnect.
