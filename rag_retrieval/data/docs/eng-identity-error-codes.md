ID-4011: access token expired; refresh the token and retry once. ID-4031: the user's account is suspended or the declined consent prevents access. ID-4033: MFA required for this action.

ID-5030: identity provider unavailable. Retry with backoff; if it persists, check the status page before paging the identity team.
